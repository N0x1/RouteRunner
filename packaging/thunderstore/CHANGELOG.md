# Changelog

## 1.3.5

First public release of Route Runner.

- Record and replay movement ghosts in exploration mode.
- Share routes as files or clipboard codes.
- Map-based library with search, bulk deletion and recovery.
- Trim recordings with previews and backups.
- Configurable keys, colours, transparency, countdown and recording limits.
- Playback speed, looping, timeline controls and return to start.
- In-game Mod Menu integration with Enable Mod and Show HUD switches.
- Compact route panel, corrected slider interaction and unlit ghost colours.
